# Floating Button

Castix provides a Floating Button workflow for supported applications.

## Typical use

Where target-app selection is provided, select the intended app, confirm the backend is authorized, enable the supported workflow, open the target app, and test.

## Accessibility relationship

Some supported interaction workflows can depend on Android Accessibility. If the button is ineffective, check the selected backend and authorization first.

## Overlay considerations

Floating controls can be affected by Android overlay rules, background restrictions, and manufacturer power management.

## Troubleshooting

If it does not appear, confirm workflow/target/backend settings and relevant Android permissions. If it appears but does not control the target app, verify target-app compatibility.
