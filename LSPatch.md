# LSPatch Backend

LSPatch is an **optional** external environment.

Official project: https://github.com/LSPosed/LSPatch

Castix does not bundle LSPatch.

## Compatibility stubs

Castix includes minimal Xposed-compatible API stubs for LSPosed/LSPatch interoperability; these are not an embedded LSPatch or Xposed runtime.

## Setup

1. Prepare LSPatch using its official project documentation.
2. Configure the Castix integration using the current LSPatch workflow.
3. Ensure the resulting application/integration is correctly configured.
4. Test the target workflow.

## Troubleshooting

Check LSPatch configuration, Castix integration presence, target-app build, Android restrictions, and target-app compatibility.

## Security

Patching and injection can materially change application behavior. Use trusted tools and APK sources.
