Usage

Castix supports several backends. The available options depend on your Android device and installed services.

1. Choose a backend

Open Castix and select a supported backend that matches your device environment.

2. Grant the required access

Follow the Android prompts or backend-specific setup required by the selected method.

3. Select the target application

Choose the application you want to use with the supported playback workflow.

4. AMOLED / black-screen mode

Use black-screen mode where supported. Castix provides configurable clock styles, scale, vertical position, spacing, and Quick Settings support.

Important

Castix does not bundle Shizuku, Dhizuku, LSPosed, LSPatch, or a root solution. Those environments must be installed and configured separately when required.
