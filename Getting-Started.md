# 🚀 Getting Started

1. Install Castix from a trusted source such as the [GitHub Releases](https://github.com/elhizazi1/Castix/releases) page.
2. Open Castix and review backend status.
3. Choose one of the six backend paths.
4. Grant the authorization required by that backend.
5. Select a target application when supported.
6. Test playback in the target app.
7. Configure optional AMOLED / black-screen mode.

### Backend choice

Accessibility is the simplest starting point for supported workflows and requires neither root nor Shizuku. Shizuku, Dhizuku, Root, LSPosed, and LSPatch are optional environments.

> [!NOTE]
> Do not assume that one backend's setup applies to another. Android version, manufacturer, ROM, battery policy, permissions, and target-app behavior can change results.

If the first test fails, use [Troubleshooting](Troubleshooting) before changing several variables at once.
