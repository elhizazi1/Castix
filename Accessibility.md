# Accessibility Backend

## What it is

Android Accessibility is one of Castix's six backend paths for supported workflows.

It requires neither root nor Shizuku.

## Setup

1. Open Castix.
2. Select Accessibility.
3. Follow the Android settings flow.
4. Enable the Castix Accessibility service.
5. Return to Castix and confirm backend status.
6. Test the target workflow.

The exact settings screen varies by Android version and manufacturer.

## Troubleshooting

If it is not detected, verify the service is enabled, re-check Castix status, inspect battery/background restrictions, and restart the device if the service state appears stale.

## Security

Accessibility is a powerful Android capability. Enable it only when you understand why the selected Castix workflow needs it.

> [!NOTE]
> Behavior may vary by Android version, device, ROM, and target application.
