# Root Backend

Root is an **optional** backend. Castix does not require root for basic operation and does not provide a root solution.

## Requirements

- A device already rooted with a compatible environment.
- A root authorization solution.
- Castix installed.

## Setup

1. Open Castix and select Root.
2. Review the root manager request.
3. Grant access only if you trust the workflow.
4. Confirm backend status.
5. Test playback.

## Troubleshooting

Verify root works independently, Castix is authorized, authorization was not revoked, and the Android/ROM environment remains compatible.

## Security

Root access can provide broad control over a device. Treat root authorization as highly privileged and never publish root credentials or secrets in issues.
