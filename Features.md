# ✨ Features

## Backend options

Accessibility, Shizuku, Dhizuku, Root, LSPosed, and LSPatch. See [Backends](Backends).

## Playback

Castix provides background playback management and related playback-restriction workflows.

## Target apps

Supported workflows can expose target-app selection. The target application's own implementation can affect results.

## AMOLED / black screen

Includes configurable clock styles, clock scale, vertical position, spacing, and Quick Settings support. See [AMOLED / Black Screen](Features-AMOLED-Black-Screen).

## Floating Button

A Floating Button workflow is available for supported applications. See [Floating Button](Features-Floating-Button).

## Multilingual UI

Arabic, English, Chinese, Japanese, French, Spanish, Portuguese, German, Italian, Russian, and Turkish are known interface languages.

## Compatibility

Android version, manufacturer, ROM, battery policies, target app, backend environment, and permissions can change behavior.
