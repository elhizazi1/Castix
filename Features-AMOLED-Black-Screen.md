# AMOLED / Black-Screen Mode

## Purpose

Provides a very dark screen for supported playback workflows. Exact visual and lock-screen behavior depends on Android and the device.

## Controls

Supported customization includes clock styles, clock scale, vertical position, and spacing.

## Quick Settings

Castix provides Quick Settings support for black-screen mode. If the tile is unavailable, check Android's Quick Settings configuration and the current Castix release.

## Workflow

1. Confirm playback works first.
2. Enable black-screen mode.
3. Select clock style.
4. Adjust scale, position, and spacing.
5. Test on the actual device.

> [!NOTE]
> Display, lock-screen, system-overlay, and power-management behavior can vary by device and ROM.

## Troubleshooting

Confirm the mode is enabled, check system screens and battery restrictions, restart Castix, and compare behavior after a reboot.
