# Background Playback

## Purpose

Castix is designed to manage background playback and related playback restrictions through supported backend paths.

## Typical workflow

1. Choose a backend.
2. Confirm authorization/status.
3. Select a target app when supported.
4. Start playback.
5. Move the target app to the background.
6. Observe the result.

## Why results differ

Battery optimization, background limits, ROM behavior, target-app lifecycle behavior, backend availability, and revoked permissions can affect playback.

## Lock-screen compatibility

Lock-screen-related playback compatibility is supported where the workflow and target application allow it; it is not a universal guarantee.

For failures, see [Troubleshooting](Troubleshooting).
