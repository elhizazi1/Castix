# Dhizuku Backend

Dhizuku is an **optional** backend environment.

Official project: https://github.com/iamr0s/Dhizuku

## Requirements

A compatible Dhizuku environment and, where required, Device Owner/device-management configuration.

## Setup

1. Prepare Dhizuku using its official documentation.
2. Confirm the required Device Owner/device-management state.
3. Open Castix and select Dhizuku.
4. Complete required authorization.
5. Confirm backend status and test.

## Troubleshooting

Verify Dhizuku is active, Device Owner state is correct, Castix is authorized, and manufacturer restrictions are not interfering.

## Security

Device Owner/device-management capabilities are powerful. Understand the administrative implications before enabling them.
